# 🗞️ Hacker News Web Scraper

A simple Python web scraper that fetches the top news headlines and their corresponding links from [Hacker News](https://news.ycombinator.com/) and saves them into a CSV file.

## 🛠️ Tech Stack
* **Python 3** 🐍
* **Requests** (Fetching web pages)
* **BeautifulSoup4** (HTML parsing)
* **CSV Module** (Data export)
